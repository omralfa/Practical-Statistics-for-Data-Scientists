## 📌 Tentang Repository

Repository ini dibuat sebagai bagian dari proses pembelajaran dan pengerjaan tugas mata kuliah **Machine Learning dan Deep Learning**.

Materi dari buku *Practical Statistics for Data Scientists* diimplementasikan menggunakan **Python** dan **Jupyter Notebook**.

Fokus utama project ini meliputi:

- implementasi konsep statistik menggunakan Python;
- eksplorasi dan analisis data;
- visualisasi data;
- perhitungan statistik;
- statistical inference;
- hypothesis testing;
- regression;
- prediction;
- interpretasi hasil analisis.

Setiap chapter disusun dalam notebook terpisah agar implementasi kode, hasil analisis, dan interpretasi dapat terdokumentasi dengan jelas.
